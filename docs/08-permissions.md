## Faculty share features
- Calendar
- Repository

### Program Chair features only
- Dashboard (for program chair only. Mostly analytics and decision making)
- Templates (can upload templates)
- Faculty page (for managing coordinators and faculty members)
- Sections (global create, edit, archive, assign, and reassign sections)
- Calendar

### Coordinator features only
- Calendar
- Templates (can upload templates)
- Sections (assigned sections only; can edit section name and header color; cannot create, archive, assign, reassign, or edit academic year)
- Dashboard (Unique to coordinator. Mostly for monitoring purposes on )


### Adviser features only
- Advisee (For progress monitoring of groups and reviewing documents)

### Panelist features only
- Panelist
