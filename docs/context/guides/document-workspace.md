# Guide: Document Workspace

**Core Idea**: When a faculty member opens a document, the workspace behavior differs depending on whether it is the initial defense document or a resubmitted document.

**Key Points**:
- **Initial Defense Document**: shows document content, the faculty member's own annotations, and other panelists' annotations/comments (to reference actual defense feedback).
- **Resubmitted Document**: shows latest content, relevant previous feedback, existing review context, and the ability to provide feedback if assigned to review the new version.
- A panelist who already approved the previous version is not required to submit another review.
- "Evaluate Document" from the Resubmissions tab lands directly in this workspace.

**Navigation Path**:
```text
Defense → Resubmissions → Evaluate Document → Document Workspace
```
